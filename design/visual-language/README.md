# Atlas Alphabet

This directory contains the canonical visual language for Atlas.

All interface, branding and documentation assets should derive from these master symbols.

## Geometry

| Element | Value |
|----------|------:|
| Thing diameter | 30 |
| Stroke width | 2 |
| Description | 30 × 30, rotated 45° |
| Relationship | 30 × 2 |

The proportions should remain constant.

Scale may vary.

Geometry should not.
